# 首页设计说明

## 目标

为校园办事小秘书提供一个以“先把一件事办好”为核心的工作台首页，降低学生查找校园流程、材料和下一步操作的认知成本。

## 视觉方向

参考 Craft 的编辑型留白与轻量工作台感，但不复制原站品牌资产。页面使用暖灰背景、低饱和橙色强调、细边框、轻阴影和 serif 标题，形成安静、可信、可继续扩展的校园工具界面。

## 本轮范围

- Vue 3 + Vite + TypeScript + Element Plus
- 首页工作台
- 模拟数据展示
- 问题输入与快捷提问反馈
- 常用服务、待办提醒、最近咨询交互
- 鼠标跟随形态：主视觉中的两层有机色块根据指针位置缓慢位移
- API 类型和 mock 接口预留

## 明确不做

- 不接入真实后端
- 不创建业务路由
- 不提交真实请假、报修或其他校园事务
- 不采集敏感身份信息
