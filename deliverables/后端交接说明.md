## 一、本次完成了什么

### 1. 后端骨架（backend_skeleton）

- FastAPI 应用工厂 `create_app`（`backend/app/main.py`），监听 8000 端口
- 配置装载 `backend/app/core/config.py`：优先级 **环境变量 > .env > 内置缺省值**，配置项 4 个（`APP_PORT`/`APP_ENV`/`DATABASE_URL`/`AGENTARTS_API_KEY`），样例见仓库根 `.env.example`（真实口令只写 `.env`，不入库）
- 统一错误体 `backend/app/core/errors.py`：404/405/422/500 → `{"error": {"code", "message"}}`，全部安全文案
- `GET /api/health` 健康检查：返回 200 `{"status": "ok"}`

### 2. 数据库建模（database_modeling）

- 四张表 ORM（`backend/app/models/`）：`service_items`、`source_documents`、`conversations`、`feedback`；三组枚举（知识状态四态、回答状态六态、反馈原因码四态）落库值与 `docs/api.md` 契约逐字一致
- Alembic 迁移（`backend/alembic/`）：`0001` 初始 schema（四张表 + InnoDB + utf8mb4）、`0002` 会话表加 `session_token` 匿名标识列（可升级可回滚）
- 会话管理 `backend/app/db/session.py`：`get_db` 依赖生成器（yield + finally 关闭）
- 脚本（仓库根 `scripts/`）：`create_database.py` 幂等建库、`seed_demo_data.py` 演示数据（S01–S08 全覆盖，单事务 upsert 幂等）
- 隐私红线：`conversations` 零 PII 字段（测试断言列白名单）

### 3. 基础业务接口（basic_business_api）

| 接口 | 说明 |
|------|------|
| `GET /api/service-items` | 支持事项查询：直接返回数组，仅 `enabled=true`，`id` 由 8 项契约映射派生（S01→student-card…），按编码升序，空表返回 200 |
| `GET /api/conversations` | 最近会话查询：请求头 `X-Session-Token`（缺失/空白直接返回空列表不查库，杜绝全量返回）；`limit` 缺省 10、范围 1–50（越界 422）；按最近消息倒序；`total` 为该标识下会话总数 |
| `POST /api/feedback` | 反馈提交：`conversation_id`/`helpful` 必填，`reason_code` 四态可空，`comment` ≤200 字；会话不存在返回 404 + `CONVERSATION_NOT_FOUND` 且零落库；成功返回 `{"status": "ok"}` |

## 三、如何跑起来

```powershell
# 1. 安装依赖（backend/.venv 已建好；队友从零开始则先 python -m venv .venv）
cd backend
.venv\Scripts\pip install -r requirements.txt -r requirements-dev.txt

# 2. 跑测试（SQLite 内存库，无需 MySQL）
.venv\Scripts\python.exe -m pytest -q

# 3. 启动服务（监听 8000）
.venv\Scripts\python.exe -m app.main

# 4. 健康检查
curl http://localhost:8000/api/health

# 5.（真实 MySQL 可用时）建库 → 迁移 → 演示数据
python scripts/create_database.py
cd backend; .venv\Scripts\python.exe -m alembic upgrade head; cd ..
.venv\Scripts\python.exe scripts\seed_demo_data.py
```

MySQL 专属行为按清单核验：`backend/docs/mysql-smoke-checklist.md`

## 六、关键设计决策速览

| 决策 | 裁决 |
|------|------|
| 测试数据库 | SQLite 内存库（零外部依赖跑 Pytest）+ MySQL 冒烟清单手动核验 |
| 枚举落库 | SQLAlchemy `Enum` + 显式 `CheckConstraint`（SQLAlchemy 2.0 起 Enum 默认不生成约束，已补） |
| 匿名标识 | 请求头 `X-Session-Token`；缺失时短路返回空响应（隐私红线） |
| 时间处理 | 统一存 UTC，序列化输出 ISO 8601 带时区（`Z` 或 `+00:00`，等价） |
| 404 分流 | 新增 `BusinessError` 异常通道，既有静态映射原样保留 |
| id 派生 | 8 项契约映射表 + 未命中全小写兜底（S09→s09） |
