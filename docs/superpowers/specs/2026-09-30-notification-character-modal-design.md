# 首页通知角色弹窗设计

## 目标

将首页右上角的“通知”按钮改造成可交互的通知弹窗入口。弹窗沿用当前校园助手的简洁、柔和主题，并吸收用户提供的卡片参考：圆角卡片、玻璃感层次、柔和阴影、角色从卡片顶部探出。

## 入口与状态

- 入口：`frontend/src/views/HomeView.vue` 顶部右侧通知按钮。
- 打开通知后清除未读红点，但不删除通知内容。
- 关闭方式：关闭按钮、点击遮罩、键盘 `Escape`。
- 弹窗打开时禁止页面背景滚动。
- 使用 `role="dialog"`、`aria-modal="true"` 和明确的标题标签。

## 视觉结构

1. 全屏遮罩：低饱和灰蓝色半透明背景，结合 `backdrop-filter: blur()`，保持首页轮廓可见。
2. 通知卡片：暖白色渐变背景、圆角、细边框和柔和阴影；最大宽度约 620px，移动端自适应。
3. 角色层：复用现有 `/assets/character.png`、`character-iris.png` 和 `character-lash.png`，角色绝对定位在卡片上方并允许溢出卡片边界。
4. 通知内容：标题、未读数量、通知条目、时间和类型标签，使用现有 CSS 变量保证浅色/深色主题一致。
5. 关闭按钮：卡片右上角圆形按钮，使用现有 sprite 图标或 CSS 绘制关闭符号。

## 角色入场动画

角色动画必须表现为两个连续阶段：

1. **手部爬上卡片**：角色初始位于卡片顶部下方，仅手部从卡片边缘逐渐向上出现；通过 `clip-path`/遮罩层与 `translateY` 控制，动画时长约 420ms，带轻微缓动和回弹。
2. **角色冒头并眨眼**：手部到位后，头部从卡片后方向上冒出，动画时长约 520ms；角色完成定位后触发一次眼睛闭合再恢复的眨眼动画，虹膜和睫毛层与现有眼动结构兼容。

动画应使用两个有序 CSS 类或 Vue 状态标记控制，避免角色和内容同时跳出。`prefers-reduced-motion: reduce` 时取消位移动画和眨眼，仅显示最终状态。

## 交互与可访问性

- 弹窗打开后将焦点放到关闭按钮或弹窗标题。
- `Escape` 关闭弹窗；点击卡片内部不关闭。
- 角色图片使用空 `alt`，避免被屏幕阅读器重复朗读；通知文本由弹窗标题和列表语义提供。
- 弹窗关闭后将焦点返回通知按钮。

## 实现边界

- 优先在现有 `HomeView.vue` 中实现，避免新增组件文件。
- 不修改现有全局主题变量，使用局部 CSS 适配当前主题。
- 不引入新依赖。
- 不覆盖用户已有的未提交修改。

## 验收标准

- 点击首页右上角通知按钮能够打开弹窗并清除红点。
- 弹窗外观与参考图一致：角色在卡片顶部探头、卡片有圆角和柔和阴影。
- 角色先完成手部爬升，再冒头，随后眨眼一次。
- 关闭按钮、遮罩、Escape 均能关闭弹窗。
- 桌面和移动宽度下布局不溢出，背景不会滚动。
- `npm run type-check` 与 `npm run build` 通过。
