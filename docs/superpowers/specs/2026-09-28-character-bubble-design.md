# 首页角色对话气泡设计

## 目标
为首页角色增加只读、不可拖拽、不可编辑的对话气泡，并复用现有设计体系的颜色与字体。

## 行为
- 首次进入首页按当前时间显示问候语：早上好、下午好或晚上好。
- 有用户资料时使用“姓名同学”；无用户资料时使用“同学”。
- 悬停或键盘聚焦导航、服务卡片、最近对话、快捷问题时显示傲娇可爱提示。
- 用户开始输入后立即显示“等待用户输入ing……”一类活泼等待文案；输入为空时恢复问候语。
- 气泡使用现有 `--surface`、`--border`、`--fg`、`--accent-soft`、`--accent` token。

## 实现边界
- 保留现有首页布局、导航跳转、输入提交逻辑。
- 使用首页中的角色作为气泡锚点，不新增角色图片或新的运行时依赖。
- 通过共享 composable 在 AppSidebar 与 HomeView 之间传递悬停消息。
- 气泡通过 `aria-live="polite"` 提供非侵入式状态播报，悬停时只更新可视文本。
- 尊重 `prefers-reduced-motion`。
